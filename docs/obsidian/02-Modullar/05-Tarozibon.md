# 05. Tarozibon Moduli

Tarozibon moduli korxona temir yo‘l tarozisi operatorlari uchun mo‘ljallangan bo‘lib, vagonlarning vazn parametrlarini aniq qayd etadi.

---

## 🎯 Asosiy Vazifalar
1. **Tara Tortish (4-bosqich):**
   - Zavodga kirgan bo‘sh vagonning tarasi o‘lchanadi (masalan: 38.26 t).
   - Fitting platformalari uchun platforma tarasi va konteyner taralari alohida hisoblanadi.
2. **Brutto Tortish (7-bosqich):**
   - Mahsulot yuklangandan so‘ng brutto o‘lchanadi (masalan: 69.14 t).
   - Tizim avtomatik `Netto = Brutto - Tara` (masalan: 30.88 t) hisoblaydi.
3. **Plomba Tasdig‘i (8-bosqich):**
   - Plombalar o‘rnatilgach, tarozi xodimi plomba raqamlarini solishtirib tasdiqlaydi.
