# Lug‘at va Terminlar

Tizimda qo‘llaniladigan asosiy qisqartmalar, kodlar va tushunchalar ro‘yxati:

| Termin / Kod | Kengaytmasi | Ma’nosi va Izoh |
| :--- | :--- | :--- |
| **IB** | Inbound Batch | **Kiritish partiyasi kodi** (masalan: `IB-0926-001`). Kengsoydan kirib kelgan vagonlar guruhi. |
| **ENP** | Entry Permit | **Kiritish xizmat xati** (masalan: `ENP-0926-001`). Zavod hududiga bo‘sh vagonlarni kiritish uchun ruxsat hujjati. |
| **DFA** | Defect Act | **Nomuvofiqlik dalolatnomasi** (masalan: `DFA-0926-001`). Nosoz yoki mahsulot yo‘qligi sababli tuzilgan hujjat. |
| **WB** | Waybill | **Yuk xati / Reyestr** (masalan: `WB-0926-001`). Chiqarilayotgan yuklangan vagonlar tarkibi uchun 6 tomonlama tasdiqlanadigan asosiy transport hujjati (Chiqarish partiyasi shu hujjat bilan yuritiladi). |
| **ShGKM** | Sho‘rtan GKM | "Sho‘rtan Gaz Kimyo Majmuasi" MCHJ (korxona hududi). |
| **Kengsoy** | Kengsoy stansiyasi | O‘zbekiston Temir Yo‘llari (O‘TY) tutashuv stansiyasi (kod: 732602). |
| **NO‘J** | Nomusulmon... / Harbiy qism | Majmuani qo‘riqlash xizmati (Qo‘riqlash xizmati harbiylashtirilgan qismi). |
| **ICHDX** | Ishlab chiqarish dispetcherlik xizmati | Majmuaning markaziy texnologik boshqaruv xizmati. |
| **TM va XA** | Tayyor mahsulot va xom-ashyo | Estakada va quyish-yuklash sexlari. |
| **Tara** | Tara og‘irligi | Bo‘sh vagonning sof og‘irligi (yuklashdan oldin tortiladi). |
| **Brutto** | Gross og‘irligi | Vagon + undagi yukning umumiy og‘irligi (yuklangandan keyin tortiladi). |
| **Netto** | Net og‘irligi | Sof mahsulot og‘irligi (`Netto = Brutto - Tara`). |
| **UNG** | O‘zbekneftegaz tarozi tizimi | Tarozi ma'lumotlarini markazlashtirilgan kiritish tizimi. |
| **Fiting platforma**| Platform wagon | 20 yoki 40 futlik konteynerlar ortiladigan maxsus temir yo‘l platformasi. |
| **Sisterna** | Tank car | Suyultirilgan gaz yoki kondensat quyiladigan maxsus temir yo‘l sisternasi. |
| **Plomba (Muhr)**| Seal | Sisterna lyuki yoki klapanlariga o‘rnatiladigan bir martalik raqamli xavfsizlik zulfi. |
